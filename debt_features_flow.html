Debt Features: Denormalized Data Build Flow

Primary builder: dash_reports/issuer_debt_in_index/data/debt.py → get_debt_df()

Scope finding: get_debt_df() creates the final wide/in-memory DataFrame. In the analyzed production code, no active write/insert into dbo.debt_features was found. The datastore and scheduled task read that table; its persistence job appears external to this flow.
source datasetstransform / combineenrichmentoutput / persistence boundary
1 — Extract source data

Bond universe

get_bond_df(asof_date)

  • ICE bond data
  • reference data / seniority
  • beta, volume, ETF change
  • OAS percentile, optional PECS

Loan universe

get_loan_df(asof_date)

  • JPM loan data
  • Markit loan price
  • loan beta / risk / OAS percentile

CDS universe

get_cds_df(asof_date)

  • Markit CDS pricing
  • CDS returns and percentile
  • IRS par rates / maturity dates

Supporting sources

  • get_fx spot FX history
  • get_issuer_id_df
  • FactSet / Findox / Markit / GeoRev
2 — Normalize and combine instruments

Filter, map, union

  • Create ticker universe from bonds and loans; retain matching CDS by ticker or ISIN.
  • Resolve CDS tickers from bond ISIN mappings.
  • Rename source-specific columns using BOND_COL_MAP and LOAN_COL_MAP.
  • pd.concat([bonds, loans, cds]) creates one instrument-level dataset.
  • Restrict to available fields in SELECT_COLUMNS; merge issuer identifiers.
3 — Market and identifier enrichment

Equity linkage

merge_factset_equity_tickers

Map bonds to FactSet equity IDs/ticker region.

Equity market data

merge_factset_equity_returns

Add equity price, market cap, volatility and return context; adds Equity rows.

FX normalization

adjust_fx_amt_fields

Convert issued/outstanding amounts to USD.

adjust_fx_oas adds cross-currency basis-adjusted OAS/yield.

4 — Instrument features and issuer curves

Derived classifications

map_columns_debt_df

  • deduplicate instrument IDs
  • rating bucket
  • maturity years / bucket
  • secured/unsecured group

Issuer curve engine (optional)

add_issuer_curve_implied_spreads

  • build SEC / UNSEC issuer curves
  • apply maturity and tenor spreads
  • calculate relative curve spreads
5 — Returns, financials, and controls

Return attribution

get_index_period_returns + add_explain_returns

Add index, beta, alpha, and bond-point return decomposition for DTD/1W/MTD/1M/QTD/YTD.

FactSet / Findox data

  • merge_factset_dcs
  • merge_factset_financials
  • merge_findox_financials
  • USD financial conversion
  • merge_factset_estimates

Issuer and compliance

  • issuer amount outstanding
  • merge_restriction_df
  • restricted issuer flag
6 — Final enrichment and output

Final data-quality / enrichment pass

  • Recalculate maturity fields and default missing secured_unsecured to UNSEC.
  • merge_georev: geographic revenue data for bonds.
  • merge_markit_bond_pricing: prefer available Markit price, OAS, yield, and duration values.
  • _merge_industry_by_ticker: fill consistent industry hierarchy by ticker.
  • fill_ticker_level_details: fill issuer/ticker-level identifiers, curve values, country, equity and geographic fields.

Final denormalized DataFrame

return debt_df

One wide dataset containing Bond, Loan, CDS, and Equity rows with market, curve, return, issuer, financial, restriction, geographic, and identifier attributes.

Persistence boundary — not implemented in this analyzed path
